# Orbit Driving School Website

A responsive static website built to closely follow the supplied Orbit Driving School homepage reference.

## Files
- `index.html` — website structure and content
- `style.css` — layout, colors, typography and responsive styling
- `script.js` — mobile navigation menu

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. An internet connection is needed for Google Fonts and the gallery/hero photos currently loaded from Unsplash.

## Hosting
Upload `index.html`, `style.css`, and `script.js` to the root of a static hosting service, such as GitHub Pages, Netlify, or your web hosting File Manager.
